# Captain Path

> Your Career. Your Airline. Your Sky.

A free, offline airline career game for Microsoft Flight Simulator 2020 and 2024. Start as a pilot, fly real contracts in MSFS, earn XP and money, get promoted, and one day run your own airline in a world of 79 airlines that lives on by itself.

**This repository only holds the game's installers and release notes.** Download the newest version from [Releases](../../releases/latest).

## Install

1. Download `CaptainPath-Setup-<version>.exe` from the newest release and run it. Windows may say "Windows protected your PC" (the installer isn't code-signed): click **More info → Run anyway**.
2. **Next → Next → Next → Install → Finish.** No administrator password is needed, and nothing else has to be installed.
3. Start **Captain Path** from the Start menu and create your pilot. To fly, start MSFS 2020 or 2024 and load your aircraft at the departure airport.

An installed game finds new versions here by itself (About → Updates) and can install them with one click. Each installer comes with a `.sha256` checksum, and the game checks every download against it.

Your save is kept in `%LocalAppData%\PilotCareer` and stays when you update or uninstall the game.
